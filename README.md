# AI Downloader

**Ollama 模型下载器** 

\---

## 它做什么

|功能|说明|
|-|-|
|**全量模型目录**|抓取 `ollama.com/library`，**一次拿到全部官方模型（实测 242 个）**；再并入官网搜索页与最新列表，去重合并|
|**下载位置绑定**|「设置 → 下载位置（模型库）」可**绑定任意目录**作为下载位置，并**自动识别该目录里已存在的模型**（含别的工具/旧安装留下的）；能探测正在运行的 Ollama 实际用的是哪个目录，不一致时给出提示与「切换并重启 Ollama」|
|**全部版本**|每个模型的**全部标签**（实测 qwen3 **58** 个、llama3.2 **63** 个、qwen3-vl **57** 个），显示**精确体积**（直接读 registry manifest，不是估算）|
|**下载线程与镜像**|下载前弹窗自选 **1–32 线程**、**可换镜像源**（支持一键测速自动选最快）；自研多线程引擎，实测比单连接快 3\~6 倍|
|**一键下载**|版本行点「下载」即入队；进度条 + **实时速度** + 剩余时间；可随时**取消**|
|**断点续传**|中断（关程序/断网）后分片保留，下次「继续下载」由 Ollama 续传；模型名会记进配置，重启程序依然可续|
|**完整性核对**|下载结束会回查 `/api/tags` 确认真的装上 —— Ollama 分块账本损坏时会“返回成功但没装”|
|**停滞检测**|180 秒无字节进展就提示，并在「已安装」页给出**清理并重下**（停服务 → 删损坏分片 → 起服务 → 重下）|
|**已安装管理**|列出本地模型（体积/参数量/量化/时间），**完全删除（含数据文件，有详细提示）**、**清理未使用数据**、**删除残留分片**|
|**按名称下载**|目录里没有的社区模型（`命名空间/模型:标签`）可直接输入名称下载|
|**服务与日志**|服务状态灯、启动/停止/重启 Ollama、目录与磁盘占用；应用日志 + 服务日志可复制|
|**外观**|深色/浅色主题、中英切换、渐变或本地图片背景（可调模糊与暗度）|

## 目录数据来源

|用途|地址|
|-|-|
|全量模型|`https://ollama.com/library`（一页返回全部官方模型）|
|补充来源|`https://ollama.com/search`、`https://ollama.com/api/tags`|
|版本列表|`https://ollama.com/library/<模型>/tags`|
|精确体积|`https://registry.ollama.ai/v2/library/<模型>/manifests/<版本>`|
|下载|本机 Ollama 服务的 `/api/pull`、`/api/delete`|

结果会缓存到 `%APPDATA%\\\\\\\\\\\\\\\\AIDownloader\\\\\\\\\\\\\\\\cache\\\\\\\\\\\\\\\\`（目录 6 小时、版本列表 6 小时），
**离线也能浏览**，右上角「刷新目录」可随时更新。

## 怎么用

双击 **`启动 AI Downloader.bat`**。

1. 「AI 模型库」页左侧列出全部模型：可按**视觉/工具/思考/嵌入**筛选，按**热门/名称/更新**排序，搜索框**本地即时过滤**；
2. 点任意模型，右侧列出它的**全部版本与体积**；
3. 点版本行的「下载」→ 左下角出现进度条（速度、剩余时间、当前文件序号），可取消；
4. 下载完成后模型出现在「已安装」页，可删除，或在「AI 模型库」里点「重新下载」。

## 绑定下载位置（自动识别已下载模型）

Ollama 只认一个 `OLLAMA\\\\\\\_MODELS` 目录 —— 换了目录，原来的模型就"看不见"了（**文件其实还在**）。
所以这里做了「绑定 + 自动识别」：

1. **设置 → 下载位置（模型库）** → 点「选择文件夹…」选中任意目录（例如原来那台盘上的 `E:\\\\\\\\Ollama\\\\\\\\models`）；
2. 点「切换并重启 Ollama」，程序会**停服务 → 用新的 `OLLAMA\\\\\\\_MODELS` 起服务**，新下载的模型就落到绑定位置；
3. 程序会**自动扫描该目录**（实测 6 个版本 / 30.87 GB **0.01 秒**扫完），把里面的模型全部列出来，
包括**服务尚未加载、但磁盘上确实存在**的（例如别的工具或旧安装留下的）；
4. 若正在运行的 Ollama 用的不是绑定目录，界面会明确提示并给出一键「切换并重启」；
5. 最近用过的位置会留成快捷按钮，随时切回。

> 扫描只读 `manifests/\\\\\\\*\\\\\\\*` 与很小的 config blob，不碰权重文件，所以再大的库也是瞬间完成。
> 若某个版本的权重缺失，会标出「缺失层」，不会被当成可用模型。

```
启动 AI Downloader.bat     启动器
app/
  main\\\\\\\_window.py          窗口外壳：画布卡片布局、导航、下载指示条、状态轮询
  views\\\\\\\_catalog.py        ★ AI 模型库：全量列表 + 版本面板 + 下载
  catalog.py              ★ 目录抓取/解析/缓存、版本与精确体积
  downloads.py            ★ 下载队列：进度、取消、续传、停滞检测、完整性核对
  mirror\\\\\\\_dl.py            ★ 多线程/镜像下载引擎（Range 分段 + 断点续传 + SHA-256 校验）
  dl\\\\\\\_dialog.py            下载前弹窗：线程数 / 下载源 / 测速
  library.py              ★ 下载位置绑定：扫描模型目录、探测服务实际目录
  panels.py               已安装 / 服务 / 设置 / 日志
  ollama\\\\\\\_api.py           Ollama HTTP 客户端 + 服务管理 + 速率计
  storage.py              磁盘层：完全删除、孤儿清理、残留分片
  widgets.py / theme.py / i18n.py / config.py / backgrounds.py
```
